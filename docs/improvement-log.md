# 改善ログ

「何を変えたら、何がどれだけ良くなったか（または悪くなったか）」を残す。数字で書けるものは数字で書く。うまく答えられなかった質問も集める。

## 書き方の例

| 日付       | 変えたこと                                           | 結果                     | 気づき                                         |
| ---------- | ---------------------------------------------------- | ------------------------ | ---------------------------------------------- |
| 2026-11-xx | 日本語の分割を `Intl.Segmenter` から bigram に変えた | 評価 20 問の正答 12 → 14 | 複合語の部分一致に強くなったが、ノイズも増えた |
